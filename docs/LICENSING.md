The addon manifest retains its original SPDX declaration. This follows the same project's existing public CLI and Lighting Workflow distribution scope.

The included Geometry Nodes Workflow source support package retains its own GPL-3.0-or-later manifest declaration and original bytes. It is distributed as the compatible run path's persistence import dependency, with separate source identity; it is not installed/enabled as a second GUI addon by this release.

Runtime modules are copied byte-for-byte to preserve the verified execution identity. Their unchanged source headers do not narrow the top-level license scope. Public documentation and skill navigation are exported adaptations; the original local maintenance skill and private evidence are retained separately.

No external runtime is bundled. Python, Blender/bpy and its components, NumPy, OpenImageIO, OpenColorIO, ffmpeg/ffprobe and codec implementations retain their own licenses and notices. A user redistributing such external software must review the actual supplied builds and their dependencies. Source packaging here does not certify an external binary distribution's license closure.

Production assets, private `.blend` files, textures/media, original acceptance images, private audit reports and Wiki are excluded. Their technical validation does not authorize publication or relicense them. Source-only synthetic fixture recipes supplied in this repository belong to this release's scope; they do not grant rights over unrelated third-party material.
